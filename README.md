# numpy-neural-networks

Учебная библиотека для глубокого обучения, реализованная с нуля на NumPy.
Цель — понять каждую формулу и каждый алгоритм через собственную реализацию,
без использования PyTorch, TensorFlow и других фреймворков.

## Установка

```bash
uv sync
```

## Запуск тестов

```bash
uv run pytest
```

С покрытием:

```bash
uv run pytest --cov=numpy_nn
```

## Проверка кода

```bash
uv run ruff check .
uv run mypy src
```

## Что реализовано

### Нейроны и слои

- [x] Нейрон МакКаллока–Питтса (`numpy_nn.nn.MPNeuron`)
- [ ] Функции активации (sigmoid, tanh, ReLU, softmax, ...)
- [ ] Полносвязный слой (Dense)
- [ ] Многослойный перцептрон (MLP)
- [ ] Функции потерь (MSE, CrossEntropy)

### Обучение

- [ ] Прямой проход (forward)
- [ ] Обратный проход (backward, без autograd)
- [ ] Gradient checking
- [ ] Xavier / He инициализация
- [ ] Learning rate schedulers

### Оптимизаторы

- [ ] SGD
- [ ] Momentum
- [ ] Nesterov Accelerated Momentum (NAG)
- [ ] AdaGrad
- [ ] RMSProp
- [ ] Adam
- [ ] AdamW
- [ ] Nadam

### Утилиты

- [ ] Экспоненциальное скользящее среднее (EMA)
- [ ] Загрузчик MNIST / Fashion-MNIST

## Структура проекта

```
src/numpy_nn/
├── nn/         # нейроны, слои, активации, лоссы
├── optim/      # оптимизаторы
├── utils/      # EMA, инициализация, schedulers, метрики
└── data/       # загрузка датасетов

tests/          # pytest-тесты
examples/       # примеры использования
notebooks/      # эксперименты и конспекты
figures/        # графики (не версионируются)
data/           # локальные датасеты (не версионируются)
```
